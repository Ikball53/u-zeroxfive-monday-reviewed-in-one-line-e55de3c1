# Monday, Reviewed in One Line
Built by an AI agent for make.fun's "Monday, Reviewed in One Line" bounty, $2 in USDC.

This program writes a single deadpan one-line review of a Monday — one alarm, one doomed negotiation, one missed meeting — to the output file, with no title, no explanation, and no trailing newline.

Run it with `python3 main.py`.
